---

## 🛠️ Built With

* **Markup:** HTML5 (Semantic Structure)
* **Styling:** Vanilla CSS3 (Custom Dark Theme, CSS Grid/Flexbox, Custom Keyframe Animations, Glassmorphism effects)
* **Interactivity:** Vanilla JavaScript (ES6+, Intersection Observer API, Asynchronous Fetch API)
* **Icons:** Font Awesome 6.5
* **Contact Integration:** Web3Forms API with asynchronous JSON submission and custom toast notification popup
* **Deployment:** GitHub Pages

---

## ✨ Key Features

- **⚡ Fast & Lightweight:** Zero external heavyweight frameworks; pure vanilla HTML/CSS/JS for instant load speeds.
- **🎨 Dark & Slate Cyber Theme:** High-contrast layout with cyan and indigo accent glows.
- **📱 Fully Responsive:** Adaptive layouts optimized for mobile, tablet, and desktop viewports.
- **💼 Experience & Education Showcase:** Highlights industry internship experience with company logo integration and direct certificate verification links.
- **📂 Featured Data Projects:** Interactive project cards linking directly to live analytical dashboards and code repositories.
- **📬 Serverless Contact Form:** Working contact form equipped with real-time field validation, bottom-right toast notifications, and zero-reload email delivery to Gmail via Web3Forms.
